# ElyOgl/homebrew-tap

Homebrew formulae by [ElyOgl](https://github.com/ElyOgl).

```bash
brew install ElyOgl/tap/vigil
```

| Formula | Description |
|---|---|
| [vigil](https://github.com/ElyOgl/vigil) | Fast, beautiful terminal system monitor: Apple Silicon P/E cores, real memory pressure, GPU, disks, network, sensors, battery and processes |

Each formula installs the prebuilt binaries attached to that project's GitHub release.
