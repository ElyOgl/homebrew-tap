# ElyOgl/homebrew-tap

Homebrew formulae by [ElyOgl](https://github.com/ElyOgl).

```bash
brew install ElyOgl/tap/mulot
```

| Formula | Description |
|---|---|
| [mulot](https://github.com/ElyOgl/mulot) | Fast, beautiful terminal system monitor: Apple Silicon P/E cores, real memory pressure, GPU, disks, network, sensors, battery and processes |

Each formula installs the prebuilt binaries attached to that project's GitHub release, and the project's release workflow updates it automatically.

`vigil` was renamed to `mulot` in 0.2.0. To switch: `brew uninstall vigil && brew install ElyOgl/tap/mulot`.
